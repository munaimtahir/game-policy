Privacy Policy

Last updated: 2026-03-19

Overview

DocBolt is an offline-first Android application used to generate deterministic clinic PDFs in a fixed template. The app is intended for use by clinics and healthcare professionals.

Data processed by the app

The app may process the following information entered by the user:

  • Patient name
  • Patient ID if entered
  • Patient age
  • Patient sex
  • Report date and time
  • Ultrasound findings selected by the user
  • Medical certificate text entered by the user
  • Generated PDF content

How data is used

The app uses this information only to:

  • build the document preview,
  • generate the PDF,
  • allow printing, and
  • allow user-initiated sharing of the generated PDF.

Data collection and sharing

  • DocBolt does not require an account.
  • DocBolt does not upload patient data to the developer.
  • DocBolt does not include cloud sync.
  • DocBolt does not include analytics or advertising SDKs.
  • DocBolt does not declare internet permission for core operation.
  • DocBolt does not sell user data.
  • DocBolt does not share patient data with third parties except when the user explicitly chooses to share a generated PDF using Android's share sheet or print framework.

Local storage

Generated documents are stored locally on the device in app-scoped storage so the user can preview, print, and share them.

Backup behavior

Automatic Android backup and device-transfer backup are disabled for this app's release configuration. Patient document files are intended to remain local to the device unless the user explicitly shares them.

Security

The app is designed to keep document generation offline and local to the device. Users are responsible for securing the device and controlling where documents are printed or shared.

Medical use and responsibility

DocBolt is a documentation utility. It does not interpret ultrasound images, make diagnoses, or provide treatment recommendations. Clinical responsibility remains with the healthcare professional using the app.

Children's privacy

The app is not designed for children as a consumer audience.

Changes

This privacy policy may be updated when the app's data handling changes.
